# SINH

## Summary

Element-wise hyperbolic sine of the input series.

## Formula

outReal[i] = sinh(inReal[i])

## Inputs

- `inReal` — Input series

## Outputs

- `outReal` — Hyperbolic sine of each input value

## Aliases

Hyperbolic Sine
