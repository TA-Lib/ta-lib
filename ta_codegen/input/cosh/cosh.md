# COSH

## Summary

Element-wise hyperbolic cosine of the input series.

## Formula

outReal[i] = cosh(inReal[i]) = (e^{inReal[i]} + e^{-inReal[i]}) / 2

## Inputs

- `inReal` — Input values to transform

## Outputs

- `outReal` — Hyperbolic cosine of each input

## Aliases

Hyperbolic Cosine
