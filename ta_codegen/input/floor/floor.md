# FLOOR

## Summary

Element-wise floor (round down to the nearest integer) of the input series.

## Formula

outReal[i] = floor(inReal[i])

## Inputs

- `inReal` — Input values

## Outputs

- `outReal` — Each input rounded down to nearest integer
