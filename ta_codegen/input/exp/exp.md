# EXP

## Summary

Element-wise base-e exponential of the input series.

## Formula

outReal[i] = exp(inReal[i]) = e^{inReal[i]}

## Inputs

- `inReal` — Input values

## Outputs

- `outReal` — e raised to each input value

## Aliases

exponential, e^x

LN · SQRT
