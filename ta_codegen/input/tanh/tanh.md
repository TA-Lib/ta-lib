# TANH

## Summary

Element-wise hyperbolic tangent of the input series.

## Formula

outReal[i] = tanh(inReal[i])

## Inputs

- `inReal` — Input value series

## Outputs

- `outReal` — Hyperbolic tangent of each input

## Aliases

Hyperbolic Tangent
