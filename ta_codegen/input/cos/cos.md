# COS

## Summary

Element-wise cosine of the input series.

## Formula

outReal[i] = cos(inReal[i])

## Inputs

- `inReal` — Input values, treated as angles in radians

## Outputs

- `outReal` — Cosine of each input value

## Aliases

Cosine, Vector Trigonometric Cos

## See Also

ACOS · SIN · TAN · COSH
