# SQRT

## Summary

Element-wise square root of the input series.

## Formula

outReal[i] = sqrt(inReal[i])

## Notes

- A negative input has no real square root, so those elements come out NaN.

## Inputs

- `inReal` — Input values

## Outputs

- `outReal` — Square root of each input value

Square Root
