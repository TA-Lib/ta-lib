# CEIL

## Summary

Element-wise ceiling (round up to the nearest integer) of the input series.

## Formula

outReal[i] = ceil(inReal[i])

## Inputs

- `inReal` — Input values

## Outputs

- `outReal` — Each input rounded up to nearest integer

## Aliases

Vector Ceil, Ceiling
