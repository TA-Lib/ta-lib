# ATAN

## Summary

Element-wise arctangent of the input series.

## Formula

outReal[i] = atan(inReal[i])  (radians, range (-pi/2, pi/2))

## Inputs

- `inReal` — Input values

## Outputs

- `outReal` — Arc tangent of each input, in radians

## Aliases

arctangent, arctan, inverse tangent
