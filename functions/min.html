Lowest value over a specified period (MIN)

Summary

Rolling minimum: the lowest input value over the trailing period.

Formula

outReal[i] = min(inReal[i-optInTimePeriod+1 .. i])

Inputs

  • inReal — Source series to take the minimum of

Outputs

  • outReal — Lowest input value over the trailing window

Parameters

ParameterTypeDefaultAccepted valuesDescription
optInTimePeriodinteger302–100000Number of bars in the trailing window

Properties

Numerical Stability: Start-Independent

✅ Overlap Input i
☐ Independent Y-Axis
☐ Candlestick
☐ Can Output NaN or ±Inf
☐ Identity at Period 1
☐ Display Shift
