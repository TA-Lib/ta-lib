TA-Lib computes technical-analysis indicators and recognizes candlestick patterns over price series. One definition per function generates the C library and native Rust, Java and C# libraries with the same functions and parameters; Python and other languages call the C library through wrappers.

This documentation is built from the main branch and can be ahead of the newest release, so any installed version, the newest included, can lack what is described here or compute different values. The [changelog](https://github.com/TA-Lib/ta-lib/blob/main/CHANGELOG.md) records each release's changes, and its "Not Released Yet" section lists changes no release has yet. [Pin the exact version](https://ta-lib.org/spec/versions/index.md#pin) when results must reproduce.

### Built for integration

- **Four native libraries, one definition.** C is the reference. Rust, Java and C# are ports, not bindings, and do not need TA-Lib's C library (no FFI, JNI or P/Invoke). All four are generated from [one definition per function](https://ta-lib.org/contribute/index.md), so names convert by a [fixed rule](https://ta-lib.org/spec/index.md#names) and a batch call takes its arguments in [the same order](https://ta-lib.org/spec/inputs-outputs/index.md#rp5) in every language. Open source under the BSD license, in use since 2001. Each API page, [Rust](https://ta-lib.org/api/rust/index.md), [Java](https://ta-lib.org/api/java/index.md) and [C#](https://ta-lib.org/api/csharp/index.md), says whether its package is published and how to add it; for C, the [C install page](https://ta-lib.org/install/c/index.md).
- **The same values in every language.** On one machine, the same call gives bit-identical results in C, Rust, Java and C#, except where it evaluates a transcendental function such as `exp` or `log`: there TA-Lib targets a difference below 1e-9 ([determinism](https://ta-lib.org/spec/versions/index.md#determinism)). Across machines, [compare with a tolerance](https://ta-lib.org/spec/versions/index.md#tolerance).
- **A page per function.** `https://ta-lib.org/functions/<name>.md`, with the name in lowercase (e.g. [RSI](https://ta-lib.org/functions/rsi.md)), gives its inputs, outputs, parameters (type, default, accepted values), numerical stability and flags; the [function index](https://ta-lib.org/functions/index.md) groups them.
- **Fast batch calls.** A batch call runs tight loops over the series: on modern AMD, Intel and Apple processors, most functions take under 10 nanoseconds per bar at their default parameters, in each of the four languages, and the slowest, such as HT_SINE, a few hundred.
- **Batch: defined values only.** A call computes the inclusive, zero-based `startIdx` to `endIdx` range and writes only the bars where the function is defined, from the start of the output buffer: `out[0]` is input bar `outBegIdx`, and `outNBElement` values follow in [C](https://ta-lib.org/api/index.md); Rust, Java and C# return the same pair as an `OutRange`. Too little data is a success with an empty range ([batch rules](https://ta-lib.org/spec/inputs-outputs/index.md)).
- **Lookback before any data.** `TA_<NAME>_Lookback(params)`, and its equivalent in each port, is the number of bars a function consumes before its first output. It depends only on the parameters and the settings in effect, never on the data, so it [validates parameters](https://ta-lib.org/spec/lookback/index.md#rl3) and [sizes outputs](https://ta-lib.org/spec/inputs-outputs/index.md#rw1) before any series exists. Ask it; never derive it from a formula ([lookback](https://ta-lib.org/spec/lookback/index.md)). No value is ever moved to another bar: where a chart draws an output elsewhere, as with ICHIMOKU's cloud, `TA_<NAME>_DisplayShift(params, outputIdx)` gives the offset.
- **Every function streams.** Open on history, update once per closed bar without recomputing the history, and peek at the forming bar without changing state. A stream gives the batch call's values over the same bars, bit for bit outside [stated exceptions](https://ta-lib.org/spec/streaming/index.md), so a live feed reproduces a backtest. A rejected bar changes nothing, and a handle clones to fork. Each language's page: [C](https://ta-lib.org/api/stream/index.md), [Rust](https://ta-lib.org/api/rust/stream/index.md), [Java](https://ta-lib.org/api/java/stream/index.md), [C#](https://ta-lib.org/api/csharp/stream/index.md).
- **Warm-up, discarded on request.** A recursive function such as EMA, RSI or ADX seeds its state from its first bars, so its early values depend on where the series starts; that is inherent to the algorithm. By default every computable value is returned. One [Auto-Stabilization](https://ta-lib.org/api/unstable-period/index.md) setting makes each such function discard the leading bars needed to reach a target number of significant digits, sized from the call's parameters ([counts and known exceptions](https://ta-lib.org/spec/auto-stabilization/index.md)); the lookback includes them.
- **Metadata and calls by name.** Every function [describes itself at run time](https://ta-lib.org/api/abstract/index.md) in all four languages and can be called by name, so a program can list the functions, build their parameter dialogs and call any of them with no code written per function; the catalog also comes as one XML document. [Flags](https://ta-lib.org/spec/abstract/index.md#flags) state what would otherwise be hard-coded per function: whether it can output NaN or ±Inf, whether its input must be positive, how a chart draws each output, which values a pattern output writes. A release may add functions and flags: [enumerate the functions, and ignore a flag you do not know](https://ta-lib.org/spec/versions/index.md#enumerate).
- **No global settings in Rust, Java and C#.** Settings live in an immutable `Core` made by a builder, so differently configured cores coexist in one process and one is shared by any number of threads with no synchronization ([settings and threads](https://ta-lib.org/spec/settings-threads/index.md)).
- **One code per fault.** A rejected batch or stream call reports one code and writes no output, the same code in every language that can detect the fault ([failures per language](https://ta-lib.org/spec/index.md#failures)).
- **A tested contract.** The [specification](https://ta-lib.org/spec/index.md) states the calling contract rule by rule, and the test suite checks every rule.
- **Candlestick patterns.** A `CDL*` output is 0 for no pattern, otherwise a signed level whose meaning its flags state ([Candlestick Outputs](https://ta-lib.org/api/candlestick-outputs/index.md)); the thresholds the patterns judge candles against are [tunable](https://ta-lib.org/api/candle-settings/index.md).
- **Python and other wrappers.** [ta-lib-python](https://github.com/ta-lib/ta-lib-python) (PyPI `TA-Lib`, `import talib`), TA-Lib's Python wrapper, calls the C library in batch and through the stream handles of `talib.stream`. Other languages: [wrappers](https://ta-lib.org/wrappers/index.md), each with its own conventions.

### Easy to miss

- **No padding.** Unlike the native APIs, ta-lib-python returns arrays as long as the input, with NaN over the warm-up, and 0 on an integer output, which on a `CDL*` output looks the same as no pattern. Code ported from Python re-aligns outputs by the begin index.
- **NaN in the input is not detected.** A NaN or ±Inf inside a batch series, or in the history a stream opens on, leaves the output undefined, and some functions carry it into every later value: clean or split the series first ([finite inputs](https://ta-lib.org/spec/inputs-outputs/index.md#finite-inputs)). A stream's update and peek reject such a bar.
- **Never compare values from [different starts](https://ta-lib.org/spec/lookback/index.md#start) bit for bit.** A [path-dependent](https://ta-lib.org/functions/stability.md) function, such as AD, OBV or SAR, may never converge. Metadata flags mark a function unstable in its own right, not one unstable only through a callee, such as DEMA or MACD through EMA ([stability from metadata](https://ta-lib.org/spec/lookback/index.md#metadata)).
- **One writer per stream handle.** No other call on a handle may run while an update or an advance runs on it. A parameter holder of the Abstract API stays on one thread, as do a Java or C# builder and the output object a Java multi-output stream writes into ([threads](https://ta-lib.org/spec/settings-threads/index.md)).
- **In C**, call `TA_Initialize` once per process before any other TA call ([initialize](https://ta-lib.org/spec/settings-threads/index.md#initialize)), and change the unstable period or the candle settings, which are process-wide, only while [no TA function runs and no stream is open](https://ta-lib.org/spec/settings-threads/index.md#idle-settings); between changes, any number of threads may call. C checks no buffer length: size every buffer yourself ([input length](https://ta-lib.org/spec/inputs-outputs/index.md#input-length), [output size](https://ta-lib.org/spec/inputs-outputs/index.md#output-size)).
