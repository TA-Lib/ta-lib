# Contributing to TA-Lib

- **Pull requests target the `dev` branch.** `main` only receives releases.
- **Request a function:** add it to the [New TA Functions board](https://github.com/orgs/TA-Lib/projects/1).
- **Implement or change a function:** follow [Contribute a TA Function](https://ta-lib.org/contribute/).
- **Build, test and maintain:** see [README-DEVS.md](README-DEVS.md).
- **Report a bug:** open a [GitHub issue](https://github.com/TA-Lib/ta-lib/issues). For a vulnerability, follow [SECURITY.md](SECURITY.md) instead.
